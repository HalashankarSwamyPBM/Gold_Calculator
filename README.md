# Gold_Socho
A comprehensive Gold Price Calculator built with HTML, CSS, and JavaScript that instantly breaks down jewelry costs, including wastage charges and 3% GST. Features an elegant Indian-market-focused layout displaying simultaneous multi-karat comparisons (22K, 20K, and 18K) alongside "True Value" tracking.
